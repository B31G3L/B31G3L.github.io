2. Überblick der Verarbeitung

Dotlist ist eine App zum gemeinsamen Verwalten von Listen und Aufgaben. Zur Bereitstellung dieser Funktionen werden Daten über Google Firebase verarbeitet und gespeichert. Ohne diese Verarbeitung ist die Synchronisation von Listen zwischen Geräten und Nutzern nicht möglich.

3. Registrierung und Anmeldung

Beim ersten Start wird automatisch ein anonymes Nutzerkonto über Firebase Authentication angelegt. Optional kannst du dich zusätzlich über Google Sign-In anmelden; dabei werden Name, E-Mail-Adresse und Profilbild deines Google-Kontos verarbeitet, um dein Konto zuzuordnen und eine Anmeldung auf mehreren Geräten zu ermöglichen.

4. In der App gespeicherte Daten

Über Cloud Firestore werden folgende Daten gespeichert:

  • Listen, Aufgaben und deren Inhalte (Titel, Beschreibung, Status, Icon, Farbe)
  • Mitgliedschaften und Rollen bei geteilten Listen (Besitzer, Admin, Bearbeiter)
  • Einladungscodes zum Teilen von Listen
  • Geräte-Token für Push-Benachrichtigungen (Firebase Cloud Messaging)

Werden Listen mit anderen Personen geteilt, sind die dort hinterlegten Inhalte auch für diese Personen einsehbar.

5. Push-Benachrichtigungen

Für Erinnerungen und Hinweise zu geteilten Listen wird Firebase Cloud Messaging genutzt. Dazu wird ein Geräte-Token an Firebase übermittelt. Benachrichtigungen lassen sich pro Liste in den App-Einstellungen stummschalten.

6. Serverseitige Verarbeitung (Cloud Functions)

Bestimmte Funktionen, etwa der Versand von Push-Benachrichtigungen bei Änderungen an geteilten Listen, laufen über Firebase Cloud Functions und greifen dafür auf die in Firestore gespeicherten Daten zu.

7. Empfänger und Drittanbieter

Dotlist nutzt Dienste von Google Firebase (Google Ireland Limited bzw. Google LLC). Es kann dabei zu einer Übermittlung von Daten in Länder außerhalb der EU/des EWR kommen. Google stellt hierfür Standardvertragsklauseln bereit. Weitere Informationen: firebase.google.com/support/privacy.
